## WEB SEARCH GUIDANCE

Use `web_search` for external facts: library docs, API behavior, error messages, version-specific syntax.

- Prefer workspace reads when the answer is in the repo
- Use focused queries; default `num_results` is 5 (max 10)
- Cite what you learned; verify against the codebase when applying fixes

Do not use web search to rediscover information already in injected context or prior tool results in this conversation.
